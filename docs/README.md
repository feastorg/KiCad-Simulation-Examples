# Docs

This folder contains the source for the GitHub Pages site.

- `introduction-to-simulations.md` and `contributing.md` are written by hand.
- `index.md`, `chapters/` and `simulations/` are generated by `scripts/generate_sim_pages.py`
  from `simulations/chapters.toml` and each example's README.
- `assets/` is filled by the docs build: schematic renders, simulated plots and the
  download bundles.
